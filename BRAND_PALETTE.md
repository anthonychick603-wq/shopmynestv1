# The Nest — Vibrant Natural Palette

Version 1.0.7 keeps the natural identity from the supplied palette while increasing saturation and contrast for mobile screens.

| Color | Hex | App use |
|---|---:|---|
| Peachtree | `#F29F82` | Seller callouts and soft danger accents |
| Forest | `#294B32` | Primary buttons, active navigation, selected controls |
| Sunflower | `#F4C84B` | Accent actions, unread emphasis, icon artwork |
| Mist | `#F6F3F0` | Main background and splash background |
| Stream | `#A9CDE5` | Information panels and secondary highlights |
| Meadow | `#B4C96F` | Borders, success surfaces, selected supporting states |
| Blossom | `#FFD9CC` | Soft cards and secondary controls |
| Fern | `#6FA05A` | Secondary brand actions and seller accents |
| Earth | `#20221E` | Primary text |

The interface uses quieter derived surface colors so the richer Forest, Sunflower, Peachtree, Stream, Meadow, and Fern tones remain readable rather than overwhelming the screen.
